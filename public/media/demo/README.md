# Demo artwork provenance
The JPEG/WebP images in this folder are cropped from the user's supplied `implementation plans/design plan/*.png` reference artwork. They are illustrative demo crops, not original full-resolution photographs and not independently licensed stock photography. The crop coordinates and source names are recorded in `src/config/demo-media.json`.

Replace these images with publication-quality, appropriately licensed originals before a real public launch. The application contains no remote stock-image requests or bundled font files. The original reference images are not redistributed in this project.
