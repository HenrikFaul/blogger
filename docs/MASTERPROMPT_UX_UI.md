## 1. BEVEZETÉS ÉS CÉLKITŰZÉSE

### Mi a cél?
Egy olyan blog platformot tervezni, amely:
- **Nem bonyolult túl** (nincs 87383 funkció)
- **Támogatja a blog írót** (creator experience)
- **Kiváló olvasói élményt** nyújt (reader experience)
- **Kereshető és SEO-barát**
- **Strukturáltan építkezik** (kategóriák, tagek, taxonomy)
- **Modern UX/UI mintákat** követ
- **Magyar és nemzetközi best practiceket** egyesít

### Kik a felhasználók?
1. **Creator (Blog Író)**
   - Könnyű, gyors szerkesztés
   - Világos dashboard
   - Analitika érthetően
   - Monetizációs lehetőségek
   - Newsletter integráció

2. **Olvasó**
   - Azonnal érthető struktúra
   - Kiváló olvashatóság
   - Könnyű navigáció
   - Gyors betöltés
   - Mobil-barát élmény

## 3. UX/UI ALAPELVEK BLOGOKHOZ

### 3.1 Vizuális Hierarchia
- H1: 2.5-3x body text méret
- H2: 1.75-2x body text méret
- H3: 1.25-1.5x body text méret
- Body: 16-18px (desktop), 16px (mobil)

### 3.2 White Space (Üres Terület)
- Szakaszok között: 60-80px padding
- Bekezdések között: 1.5-2x line-height
- Oldalsó margók: minimum 20px (mobil), 40-60px (desktop)

### 3.3 Színrendszer
- Body text: minimum 4.5:1
- Nagy szöveg (18px+): minimum 3:1

### 4.2 Sorhossz (Measure)
- Optimális sorhossz: 55-75 karakter (max-width: 65ch vagy 600-750px)

### 5.3 Blog Post Page (Cikk oldal)
- Tartalomjegyzék (TOC) sticky sidebar
- Kapcsolódó cikkek a végén
- Max-width: 65ch (600-750px)

### 8. SEO ÉS TECHNIKAI OPTIMALIZÁLÁS
- H1 tartalmazza a fő kulcsszót, Meta description max 160 karakter
- LCP < 2.5s, CLS < 0.1
- Keppek: WebP/AVIF, lazy-load
- Schema.org (BlogPosting, Author)

## 10. ACCESSIBILITY ÉS WCAG IRÁNYELVEK
- Billentyűzettel is használható (Tab, Enter, Esc)
- Focus state látható
- Alt text minden képen
- Kontraszt 4.5:1 (normal text)
